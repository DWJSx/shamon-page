Get Started

Set up once, then let your AI agent handle the CLI

You manage connections and approvals in the desktop app; your coding agent discovers and invokes shamon on its own.

1

Install the macOS app

Download the notarized DMG, launch Shamon, and enable the shamon CLI link in Settings so your local agents can find it.

2

Connect your resources

Link the Chrome Connector extension for approved websites, or add your PostgreSQL, MySQL, ClickHouse, and SSH connections in the app.

3

Ask your AI agent

Tell your coding agent to use shamon. It discovers the catalog automatically and executes only within the permissions you granted.

Example prompts you can give your AI agent
  • “Use Shamon to inspect the API calls on this dashboard and package a reusable read command.” Browser
  • “Query the primary database via Shamon and check why today’s sync count dropped.” Database
  • “Check the service status on the staging host through Shamon SSH.” SSH
Chrome Connector

Companion Chrome extension setup

Shamon Connector connects Chrome to the local Shamon app for user-approved browser requests, command-requested localStorage reads, and explicit network investigation sessions.

1

Copy your local token

In the Shamon macOS app, open General → Chrome Extension to see your local port and copy the generated token.

2

Configure allowed origins

Open Shamon Connector settings in Chrome, enter 127.0.0.1:<port>, paste the token, and add the exact origin patterns you want to approve.

3

Approve & revoke anytime

Review the privacy notice and grant Chrome site access. Removing an origin or clicking Disconnect and clear data immediately revokes access.

Security & Privacy

Explicit permissions and local-only boundaries

Shamon is built so you decide exactly which sites, credentials, and commands your local agents can reach.

Loopback-only connection
Shamon Connector communicates exclusively with 127.0.0.1 or localhost and requires the user-configured shared token for every WebSocket connection.
Origin allowlist enforcement
The extension requests no site permissions on install. Every browser fetch, read-only localStorage lookup, and debugger session checks your approved origins and rejects redirects outside that list.
Local-only storage & instant revocation
Extension tokens and settings live only in Chrome local storage (never Chrome Sync). Changing origins detaches active debugger sessions, and Disconnect and clear data revokes optional site permissions immediately.
No remote code execution
All executable code in Shamon Connector is bundled in the reviewed package without obfuscation or minification. The extension never downloads or evaluates remote scripts.
