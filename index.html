Capabilities

One local runtime for browser, data, and command workflows

Built for developers and coding agents that need deterministic, authenticated access to real environments without scattering credentials.

Browser

Browser-backed requests & network inspection

Execute HTTP requests using your real Chrome session and run explicit investigation sessions that retain up to 10,000 network requests for inspection—strictly limited to origins you approve.

Adapters

Sandboxed JavaScript commands

Add single-file Workers-style adapters under ~/.shamon/commands/. Commands execute in an isolated QuickJS-NG context with no filesystem, process, socket, or eval access.

Databases

PostgreSQL, MySQL, and ClickHouse

Configure database connections once in the Shamon app and run queries from the standalone CLI through the bundled Toolbox binary—database secrets stay out of CLI processes.

Infrastructure

Managed SSH & Keychain vault

Run managed command-only SSH sessions and store connector credentials in macOS Keychain. Every local CLI request is authenticated against the loopback RPC server.

Chrome Connector

Link Chrome to your local Shamon app

Shamon Connector is the companion Chrome extension for browser-backed requests, command-requested localStorage reads, and explicit network investigation sessions.

1

Install the macOS app

Download and launch the notarized Shamon macOS release. Open General → Chrome Extension to view your local port and copy the generated token.

2

Configure Shamon Connector

Click the extension icon in Chrome, enter 127.0.0.1:<port>, paste the token, and list the exact origin patterns you want to allow.

3

Approve access & run

Review the privacy notice, grant Chrome site access for those origins, and run shamon request or shamon browser research from Terminal.

Read the Shamon Connector Privacy Policy

Browser data is sent only over local loopback to your Shamon app. No developer collection, no ads, no third-party sharing.

Quick Start

Inspect APIs and package reusable commands

Install the shamon CLI symlink from Settings, inspect a live browser workflow, then turn it into a validated local command.

Terminal 
# Check app, CLI, and extension health
$ shamon doctor

# Open an approved site and inspect network traffic
$ shamon browser research open https://example.com/
$ shamon browser research network
$ shamon browser research close

# Validate a custom JavaScript adapter
$ shamon check ~/.shamon/commands/demo/get.js
~/.shamon/commands/demo/get.js 
export const command = {
  summary: "Read a JSON resource",
  access: "read",
  arguments: [{ name: "id", required: true }],
  hosts: ["example.com"],
  example: "shamon demo get 123"
};

export default {
  async fetch(request) {
    const { args } = await request.json();
    const res = await fetch(`https://example.com/api/${args.id}`);
    return Response.json(await res.json());
  }
};
Security & Privacy

Explicit permissions and local-only boundaries

Shamon is designed so you stay in control of which sites, credentials, and commands are accessible at all times.

Loopback-only connection
Shamon Connector communicates exclusively with 127.0.0.1 or localhost and requires the user-configured shared token for every WebSocket connection.
Origin allowlist enforcement
The extension requests no site permissions on install. Every browser fetch, read-only localStorage lookup, and debugger session checks your approved origins and rejects redirects outside that list.
Local-only storage & instant revocation
Extension tokens and settings live only in Chrome local storage (never Chrome Sync). Changing origins detaches active debugger sessions, and Disconnect and clear data revokes optional site permissions immediately.
No remote code execution
All executable code in Shamon Connector is bundled in the reviewed package without obfuscation or minification. The extension never downloads or evaluates remote scripts.
