Shamon Connector Privacy Policy

Effective November 17, 2026

Shamon Connector links Chrome to the Shamon companion app running on the same device. It processes browser data only when needed for a user-initiated browser request or investigation session and only for origins the user has entered and approved.

Data processed

The extension may process:

  • approved page URLs and titles;
  • request and response URLs, methods, status codes, and headers;
  • request and response bodies requested by the user;
  • individual website localStorage values explicitly requested by a command, including authentication tokens used to construct API headers; and
  • connection settings, including a local Shamon address, a locally stored access token, the approved-origin list, and the user's consent choice.

Website traffic can contain website content, browsing activity, authentication information, personal information, or communications. Shamon Connector does not inspect sites outside the approved-origin list.

How the data is used

Browser data is used solely to perform the extension's single purpose: executing browser-backed requests and showing network details to the user through the local Shamon app. It is not used for advertising, profiling, credit decisions, or unrelated analytics.

Sharing and transmission

The extension sends browser results only over the device's loopback interface to the Shamon app selected by the user. The extension developer does not receive this data. The extension does not sell user data or share it with advertisers, data brokers, or other third parties.

Storage and retention

Connection settings, the access token, and the approved-origin list are stored locally by Chrome on this device and are not placed in Chrome Sync. The token is used to authenticate the local Shamon connection and is removed by “Disconnect and clear data” or uninstalling the extension. Network history is retained in extension memory only for the active investigation session, up to the extension's bounded session limit. Data deliberately exported by the user through Shamon is controlled by the user and the Shamon app.

Website localStorage reads are read-only. Their values pass through memory to the local command runtime and are not copied into extension settings or logs. The extension closes each temporary read tab on completion, error, or timeout.

User control and deletion

Users choose every eligible origin through the extension settings and may remove an origin at any time. The “Disconnect and clear data” action revokes optional site access and deletes locally stored extension settings. Uninstalling the extension also deletes its local Chrome storage.

Security

The companion connection is restricted to the local loopback interface and authenticated with a user-provided token. The extension accepts only packaged command types and does not download or execute remote code. Approved website origins may use HTTP or HTTPS. HTTP is provided for development services that do not offer TLS; its traffic is not encrypted and should be used only with trusted services. Redirects outside the approved origin list are rejected.

Limited Use

The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes and contact

Material changes to these practices will be disclosed before the changed data handling begins. Questions about this policy can be sent through the support channel published at shamon.net.
